# inc1-b2b-500

## Причина
Сайт обращается к старой базе данных. Файл .env был изменен при деплое, но кэш конфигурации не был очищен, что видно в файле deloy.log.

## Доказательство
В **env_excerpt.txt** фале стоит **DB_HOST=db-new.example.test**, а в файле **ls_bootstrap_cache.txt** значение **'host' => 'db-old.example.test'**.

## Что сделать сейчас
Необходимо на сервере выполнить следующие команды:
1. `php artisan config:clear` - для очистки кэша конфигурации.
2. `php artisan cache:clear` - для очистки основного кэша.
3. `php artisan config:cache` - для создания актуального кэша.

### Проверка
Открыть сайт в инкогнито, и проверить laravel.log.

## Как не допустить повторения:
1. Добавить процесс очистики кэша в дальнешем после `php artisan migrate --force` и до `php artisan up`. Или создать sh-скрипт для деплоя.
2. С делать автоматический HTTP-мониторинг с отправкой сообщений при получении кодов ответа 5XX сразу после завершения деплоя.


## Ответ сотруднику
Сайт временно выдавал ошибку из-за устаревших системных настроек, после вчерашненго обновления. Необходимые технические работы проведенны, в ближайшее время стайт полностью возобновит свою работу.
